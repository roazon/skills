# Security policy

This repository contains public instructions for an anonymous, read-only search API. It does not issue or handle API keys.

Please report vulnerabilities privately through the repository's **Security → Report a vulnerability** feature if GitHub enables private vulnerability reporting for this repository. If that option is unavailable, contact the maintainers through the contact link on [Roazon's About page](https://roazon.nl/about/) and ask for a private security reporting channel. Do not include credentials or personal data in a public issue.

Include the affected file or endpoint, impact, and steps to reproduce. Please allow maintainers time to investigate before public disclosure.
